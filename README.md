# ModelSim FPGA Projects

A collection of FPGA/Verilog projects simulated using ModelSim.

## Projects

| Project | Description |
|---------|-------------|
| **5 stage risc** | 5-Stage Pipelined RISC-V Processor (IF, ID, EX, MEM, WB) |
| **basic Risc** | 2-Stage Basic RISC-V Processor |
| **ALU** | 4-bit Arithmetic Logic Unit |
| **ATM** | ATM Controller FSM |
| **FSM_Example** | Washing Machine FSM (SystemVerilog) |
| **fsm_verilog** | Washing Machine FSM (Verilog) |
| **dff** | D Flip-Flop |
| **hf** | Half Adder |
| **hfm** | 4-bit Half Adder |

## Tools Used
- **ModelSim** - HDL Simulation
- **Verilog / SystemVerilog** - Hardware Description Language

## Structure
Each project folder contains:
- \*.v\ / \*.sv\ - Source design files
- \*_tb.v\ / \*_tb.sv\ - Testbench files
